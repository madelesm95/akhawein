# شريط الإعلانات ولوحة التحكم

شريط رفيع أسفل شريط التواصل وأعلى الهيدر، يعرض إعلانًا واحدًا في كل مرة مع إمكانية التنقل وإغلاق الشريط.

الإعلانات تُدار من **لوحة تحكم داخل الموقع** على المسار `/admin` (محمية بكلمة مرور)، وتُحفظ في تبويب `Announcements` داخل Google Sheet الجمعية عبر بوابة Apps Script الموجودة أصلًا. بعد الإعداد الأول لا تحتاج إلى `npm run build` أو إعادة نشر عند إضافة إعلان أو تعديله.

> متصفح الزائر لا يتصل بـ Google مباشرة: الصفحة تقرأ `/api/announcements` من خادم الموقع، والخادم هو الذي يقرأ الشيت ويكتب فيه.

## 1) الإعداد لمرة واحدة

### أ) تحديث Apps Script

1. افتح الشيت المستخدم للتبرعات → **Extensions → Apps Script**.
2. استبدل محتوى `Code.gs` بالنسخة الموجودة في المستودع: `google-apps-script/Code.gs`.
3. احفظ (**Ctrl+S**)، ثم شغّل الدالة `setup()` مرة واحدة واسمح بالأذونات.
   - ينشئ `setup()` تبويب `Announcements` إذا لم يكن موجودًا، ويطبع `SHEETS_WEBHOOK_SECRET` في سجل التنفيذ.
   - لو كان السر موجودًا من قبل، يطبع نفس القيمة القديمة ولا يغيّرها.
4. أعد نشر نفس النشرة بإصدار جديد: **Deploy → Manage deployments → تعديل (قلم) → Version: New version → Deploy**.
   - رابط النشرة `.../exec` لا يتغيّر عند إعادة النشر.
   - لا تنشئ نشرًا جديدًا؛ النشر الجديد يعطي رابطًا مختلفًا.

### ب) متغيّرات Vercel

في **Vercel → Project → Settings → Environment Variables** أضف:

| المتغيّر | مطلوب | الشرح |
|---|---|---|
| `SHEETS_WEBHOOK_URL` | نعم | رابط نشر Apps Script (`https://script.google.com/macros/s/.../exec`). |
| `SHEETS_WEBHOOK_SECRET` | نعم | نفس السر الذي طبعه `setup()`. |
| `ADMIN_PASSWORD` | نعم للوحة | كلمة مرور اللوحة. استخدم 16 حرفًا عشوائيًا على الأقل. لو فارغة تظهر اللوحة كغير مهيأة. |
| `ADMIN_TOKEN_SECRET` | لا | مفتاح منفصل لتوقيع جلسات اللوحة. لو لم يُضبط يُستخدم `ADMIN_PASSWORD` نفسه. |

بعد إضافة المتغيّرات أعد نشر الموقع (**Redeploy**) حتى تُقرأ القيم الجديدة.

### ج) أول دخول

1. افتح `https://www.akhawein.org/admin`.
2. أدخل `ADMIN_PASSWORD`.
3. لو التبويب فارغ، اضغط **«إضافة 12 إعلاناً جاهزاً»** لإدراج الإعلانات المبنية على محتوى الموقع الحالي (غزة، فك كرب، كفالة الأيتام، إطعام، الغسيل الكلوي، تجهيز العرائس، حملة دفا، ذوو الهمم، قصة مؤيد، أمنية لأطفال الأورام، كرتونة الخير، قصة صابر). الزر يظهر فقط عندما تكون القائمة فارغة، وإعادة الضغط آمنة لأن الحفظ يستبدل بنفس المعرّف.
4. أو اضغط **«إعلان جديد»** واكتب أول إعلان يدويًا.

## 2) الاستخدام اليومي

من `/admin` بعد تسجيل الدخول:

- **إعلان جديد / تعديل:** النص العربي مطلوب. لو النص الإنجليزي فارغ يظهر العربي في الصفحة الإنجليزية باتجاه RTL.
- **الوسم (Tag):** كلمة قصيرة تظهر قبل النص، مثل «عاجل» أو «شتاء».
- **لون الوسم:** `ذهبي` أو `أخضر` أو `أحمر` أو `كحلي`.
- **الأولوية:** رقم من 0 إلى 1000. الأعلى يظهر أولًا.
- **تبدأ في / تنتهي في:** تاريخ ميلادي `YYYY-MM-DD`. النهاية شاملة لليوم كاملًا. اتركهما فارغين لإعلان دائم.
- **الرابط:** مسار داخلي مثل `/causes#cause-gaza-relief` أو رابط خارجي يبدأ بـ `https://`، أو `mailto:` / `tel:`.
- **ظاهر في الشريط:** أزل العلامة لإيقاف الإعلان مؤقتًا بدون حذفه.
- **حذف:** يحذف الصف نهائيًا من الشيت بعد تأكيد.

حالة كل إعلان تظهر في القائمة: «ظاهر الآن»، «لم يبدأ»، «منتهي»، أو «موقوف».

الجلسة تنتهي تلقائيًا بعد 8 ساعات أو عند إغلاق التبويب. تسجيل الدخول محدود بـ 6 محاولات كل 10 دقائق لكل عنوان IP، وعمليات الحفظ/الحذف محدودة بـ 90 عملية في الساعة.

## 3) أعمدة تبويب `Announcements`

اللوحة تُنشئ التبويب وتكتب هذه الأعمدة تلقائيًا. لا تعدّل `id` أو `updated_at` يدويًا؛ استخدم اللوحة.

| العمود | إلزامي | الشرح |
|---|---|---|
| `id` | نعم (تلقائي) | معرّف ثابت بصيغة `ann-...`. الحفظ يستبدل الصف الذي يحمل نفس المعرّف. |
| `active` | لا | `TRUE` أو `FALSE`. الفارغ يُعتبر مفعّلًا. |
| `start` | لا | تاريخ البداية `YYYY-MM-DD`. فارغ = يبدأ فورًا. |
| `end` | لا | تاريخ النهاية `YYYY-MM-DD` (شامل اليوم). فارغ = بلا نهاية. |
| `priority` | لا | رقم؛ الأعلى يظهر أولًا. الافتراضي 0. |
| `tag_ar` / `tag_en` | لا | وسم عربي/إنجليزي قصير. |
| `text_ar` | نعم* | نص الإعلان بالعربية (حتى 600 حرف). |
| `text_en` | لا | النص الإنجليزي. لو فارغًا يظهر العربي. |
| `url` | لا | رابط داخلي أو خارجي. |
| `link_ar` / `link_en` | لا | نص رابط التفاصيل. الافتراضي «التفاصيل». |
| `tone` | لا | `gold` (افتراضي)، `green`، `red`، `navy`. |
| `updated_at` | تلقائي | آخر تعديل بتوقيت ISO. |

\* يكفي أن يكون `text_ar` أو `text_en` غير فارغ.

التواريخ تُقيَّم بتوقيت **أفريقيا/القاهرة**، لا بتوقيت المتصفح.

## 4) سلوك الشريط

- **التحديث:** يقرأ المتصفح `/api/announcements` عند فتح الصفحة، مع كاش في `sessionStorage` لمدة `refreshMinutes` (افتراضيًا 5 دقائق) لكل تبويب.
- **الجدولة:** الإعلانات خارج نطاق `start`/`end` أو الموقوفة لا تظهر. لو لم يتبقَّ إعلان نشط، يختفي الشريط بالكامل.
- **الأولوية:** ترتيب تنازلي، وبحد أقصى `maxItems` (افتراضيًا 12).
- **الاحتياطي:** لو تعذّر الوصول إلى الشيت، تظل النسخة المدمجة من `fallback` في `src/content/announcements.mjs` ظاهرة داخل HTML.
- **الإغلاق:** زر الإغلاق يخفي الشريط لمدة 7 أيام في نفس المتصفح (`localStorage`).
- **الحركة:** يتوقف التبديل عند المرور بالماوس أو التركيز بالكيبورد، ويحترم `prefers-reduced-motion`. زرّا السابق/التالي يعملان دائمًا.
- **الصفحات الإنجليزية:** لو `text_en` فارغ، يظهر النص العربي مع اتجاه RTL. الروابط الداخلية المعروفة تتحول تلقائيًا إلى مسار `/en/...`.

## 5) الإعدادات في `src/content/announcements.mjs`

```js
enabled: true,                 // false لإخفاء الشريط من الموقع بالكامل
source: '/api/announcements',  // مصدر القراءة (أو رابط CSV منشور، أو ملف CSV محلي)
refreshMinutes: 5,             // أقل مدة بين قراءتين في نفس التبويب
maxItems: 12,                  // أقصى عدد إعلانات
rotateMs: 7000,                // مدة ظهور كل إعلان
fallback: [ ... ],             // النسخة المدمجة في HTML
```

`source` يمكن أن يكون:

- `/api/announcements` — الوضع الافتراضي، ويشمل الكتابة من اللوحة.
- رابط Google Sheets منشور (`...output=csv`) — للقراءة فقط، بدون لوحة تحكم.
- `/assets/data/announcements.csv` — ملف محلي للعرض أو التجربة.

## 6) تجربة محلية

1. انسخ `.env.example` إلى `.env.local` وأضف `SHEETS_WEBHOOK_URL` و`SHEETS_WEBHOOK_SECRET` و`ADMIN_PASSWORD`.
2. شغّل `npm run dev` وافتح `http://localhost:5500/admin`.
3. الأمر `npm run build` لا يلزم بعد كل تعديل في اللوحة؛ يلزم فقط عند تغيير ملفات الصفحات أو التصميم.

ملف `assets/data/announcements.csv` جاهز كنسخة استيراد بنفس أعمدة تبويب `Announcements`، ويحتوي الإعلانات الخمسة الجاهزة.

## 7) استكشاف الأخطاء

| المشكلة | السبب المحتمل |
|---|---|
| «لوحة التحكم غير مهيأة» | `ADMIN_PASSWORD` غير مضاف في Vercel، أو أُضيف دون إعادة نشر. |
| «تعذّر الحفظ في Google Sheets» | `SHEETS_WEBHOOK_URL` أو `SHEETS_WEBHOOK_SECRET` غير صحيح، أو Apps Script لم يُنشر بإصدار جديد، أو `setup()` لم يُشغَّل. |
| «انتهت الجلسة» | انقضت 8 ساعات، أو تغيّر `ADMIN_TOKEN_SECRET` / `ADMIN_PASSWORD` بعد إصدار الرمز. سجّل الدخول من جديد. |
| الشريط يعرض الإعلانات القديمة | كاش `refreshMinutes`، أو كاش الحافة (حتى دقيقتين). افتح تبويبًا جديدًا أو انتظر. |
| الشريط يظهر بالنسخة الاحتياطية فقط | `/api/announcements` يرجع خطأ. راجع Vercel → Functions → Logs، وتأكد من متغيّرات البيئة. |
| إعلان لا يظهر | تحقق من «ظاهر الآن» في اللوحة، ومن `start`/`end`، ومن وجود نص عربي أو إنجليزي. |
| اختفى الشريط | لا توجد إعلانات نشطة، أو تم إغلاقه من زر الإغلاق (يُمسح بعد 7 أيام). |
| زر «إضافة الإعلانات الجاهزة» لا يظهر | القائمة ليست فارغة؛ الزر يظهر فقط عند عدم وجود أي إعلان. |
| نسيت كلمة المرور | غيّر `ADMIN_PASSWORD` في Vercel وأعد النشر. غيّر `ADMIN_TOKEN_SECRET` أيضًا لإبطال الجلسات المفتوحة فورًا. |

## 8) الأمان والخصوصية

- كلمة المرور تُقارن على الخادم فقط، ولا تُرسل إلى المتصفح.
- رمز الجلسة موقّع بـ HMAC-SHA256، ويُحفظ في `sessionStorage` وينتهي بعد 8 ساعات.
- كل عمليات الكتابة تتحقق من الأصل (Same-Origin) ومن الرمز، وتخضع لحدود معدّل.
- لا تُخزَّن بيانات شخصية في تبويب الإعلانات؛ اكتب محتوى إعلانيًا عامًا فقط.
- متصفح الزائر يطلب `/api/announcements` من موقعنا فقط، ولا يتصل بـ Google. أُضيف ذلك إلى سياسة الخصوصية.
